# Olanga 1.6.2

Local build for the live NBA score card. This build has not been published to GitHub Releases.

- Pin a small score card beside Olanga's corner orb from **Settings → User preferences → Live scores**.
- Golden State Warriors is selected initially; choose any of the 30 NBA teams.
- Scores refresh about every 15 seconds during play. The card shows the provider's quarter and game clock, next matchups and final results. Feed delays and failed refreshes are clearly marked.
- Score checks run without AI calls or provider keys. Timed hiding, unpinning and computer sleep pause requests; returning refreshes the card automatically.
- Settings persist through restart. The updated privacy notice explains the public requests to ESPN.

The installer retains existing app data and preferences. Live scores are opt-in. This local installer is unsigned, like previous builds; no automatic update or public release is created.
