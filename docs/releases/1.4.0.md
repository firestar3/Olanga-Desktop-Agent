# Olanga 1.4.0

Olanga 1.4.0 adds streamed spoken replies, a local Workspace, reminders, memories and more ways to start a conversation from your Windows desktop.

## What's new

- **Streamed replies:** eligible conversational answers begin speaking sentence by sentence while Gemini finishes generating the response. The classic reply mode remains available in Voice Settings.
- **Push-to-talk and voice interruption:** choose a global shortcut to start recording and press it again to send, or say “Hey Olanga” to interrupt a spoken reply. Both controls are configurable.
- **Reminders, alarms and daily briefings:** save reminders and clock alarms locally, then ask for a briefing with your tasks, timers and available headlines or weather. Olanga must be running for alarms to sound.
- **Workspace:** review routines before running them, inspect action results, save app and playlist aliases, and resume unfinished routine steps without repeating completed work.
- **Memories and health checks:** review or delete facts you explicitly ask Olanga to remember, control whether they are used in answers, and check local voice, storage and provider readiness.
- **Optional on-device speech:** use the bundled English recognizer and review its transcript before submitting. Typed local commands work without a Gemini key.
- **Native app controls:** verify supported app launches and window arrangements. Graceful close requests match exact processes and report pending windows or save prompts.

## Reliability improvements

Speech cancellation, microphone and offline-worker recovery, streamed response handling, native helper failures and secure credential migration have additional regression coverage. Notes and file imports preserve intervening edits; news refreshes reject stale results; failed local saves report their outcome without silently changing durable state.

## Install or update

Download **Olanga-Setup-1.4.0.exe** from this release. Quit any running Olanga instance from its tray menu before installing, then reopen it from your desktop or Start-menu shortcut. Provider features use your own Gemini key; NVIDIA Magpie speech is optional and uses a separate key.

Updates remain manual. See the README for features, setup and current limits, and the release's verification notice below for checksums and signing status.
