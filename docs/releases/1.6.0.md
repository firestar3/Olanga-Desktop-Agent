# Olanga 1.6.0

Olanga now gives you clearer results, safer personal storage and a more useful News panel, while keeping Workspace and the familiar visual style at the center of the app.

## Memory that stays organized

Recent conversation stays bounded and expires automatically after inactivity. Saved memories have search and sorting in Workspace. Deleting or disabling a memory removes dependent local conversation context and stops a pending reply that was using it; unrelated local-command history remains available. There is no New conversation button.

Choose natural or concise replies and an optional preferred form of address in User preferences. These choices affect wording, never permissions or verification.

## Personal backups and recovery

Export and review a backup of saved memories, app aliases, saved playlist names and routine definitions. Import shows what will change before replacing that content, and never runs imported routines. Keys, settings, timers and activity are excluded.

Damaged or newer-version Workspace data is preserved instead of silently overwritten. Recovery requires a verified copy before a reset. Raw recovery copies remain on this device until you delete them; they can contain older activity and other private content. See [Privacy](../../PRIVACY.md).

## News you can read directly

Choose topics and a 6-, 12- or 18-story view. Headlines include publishers, dates, links and labeled source excerpts. Relevance, freshness, duplicate filtering and publisher diversity help shape the digest. A failed feed no longer discards the other results.

Mark stories as read, filter to unread stories, or refresh when you want another look. News opens without an automatic model-generated article. AI questions are optional and use the loaded headline information.

## Clearer controls and results

- User, Core and Privacy settings separate everyday preferences from connection setup. The page uses the available window width, with responsive columns, comfortable spacing and reachable controls in short windows.
- Five accents, contrast, glow and reduced-motion controls preserve the original default appearance.
- Home controls remain reachable in short windows. Notes wraps its toolbar and stacks its assistant in narrow windows, including enlarged text.
- Projects, Schedules and Updates have direct Workspace entry points. Command examples fill the input for review.
- Core settings has an explicit Gemini connection test beside the key controls.
- Completed action results appear immediately, even while acknowledgment audio is finishing. Local diagnostics distinguish acknowledgment dispatch, the playback-start event and action completion.
- The privacy notice and fonts are bundled for offline access.

## Manual updates with a verified restart

The updater shipped in this version binds restart readiness to the update attempt and expected installed version. Success requires an initialized renderer, a visible window and usable controls. Stale or incomplete attempts show recovery information instead of verified success.

The update **into** 1.6.0 still uses the updater in your previously installed version. The readiness protocol does not retroactively change older helpers. Updates remain user initiated: Check, Download, then Install & restart.

## Build and validation

The Windows installer is unsigned; no publisher certificate has been supplied. Compatibility tests use disposable profiles and fixtures. They do not establish live Spotify playback, physical-microphone quality or universal performance guarantees.

See [Validation](../VALIDATION.md) for measured results and remaining limits. Local build output is separate from a published GitHub release.
