# Olanga 1.5.2

Olanga does less work while you are not using it, and in-app installation now stays visible through completion. The built-in Terminal has been removed.

## Updates you can follow

Choose **Workspace → Apps & updates → Check for updates**, then **Download update** and **Install & restart**. Updates remain manual.

From this version onward, Olanga checks that its update helper is ready before closing. A separate progress window stays open while the installer runs. The helper checks the installer exit and installed version, then reopens the exact Olanga executable. Failed installation attempts produce a recovery result instead of treating a process launch as completion. The reopened app comes to the foreground, including updates started by older Olanga versions.

Your existing installation location, settings and saved data are preserved. For a new installation, download **Olanga-Setup-1.5.2.exe** from this release.

## Less background work

- The main window no longer asks Windows to blend a transparent fullscreen surface behind an already solid page. Its rendered appearance is unchanged.
- Hidden or minimized windows stop drawing animations. Active visible animations retain their normal motion.
- Timer displays share one scheduler. Deadlines remain active in the tray and catch up when the window returns.
- The microphone reuses the audio capture samples for level detection, avoiding a second analyser loop.
- Muting the microphone suspends its audio processing immediately. After five seconds, an unused local recognition model is released. Unmuting reloads the cached model when needed.
- Typed-only and muted startup defer loading the speech library. The recognition model and command vocabulary are unchanged.
- Empty schedules, inactive local speech and the hidden corner overlay stop unnecessary polling.

In a paired Windows benchmark against 1.5.1, CPU use fell 54% with the idle window visible, 99% while idle in the tray and 87% while muted in the tray. Private resident memory after sustained mute fell 40–45%. Active voice recognition showed smaller savings; this is not a claim of halving CPU and RAM in every state. [Full measurements and validation](../VALIDATION.md).

After the unused recognition model is released, unmuting reloads it. Full model readiness took about 2.7 seconds in this run; audio capture resumes concurrently. Short mutes keep the model warm.

## A simpler app

Terminal is removed from navigation, Settings and the packaged application. Its shell sessions and command-execution endpoints are removed as well. Notepad, News and Workspace remain available.

The transparent purple orb remains consistent across the application, installer and Windows shortcuts. The Windows tray now uses a dedicated, tightly framed orb without the outer halo, so it fills the small icon area with transparent corners.
