# Olanga 1.6.1

Olanga 1.6.1 brings conversational learning, faster local memory answers and quieter background voice processing, alongside fixes to recording, navigation and microphone recovery.

## Memory that works with the conversation

- With conversational learning enabled, Olanga can retain useful preferences and recurring details from normal requests. Learned details share the organized local memory list; explicit memories stay protected from silent replacement.
- Ask what Olanga remembers, which memories it used, or ask it to stop learning. Relevant local memory answers use the local path when they can be answered directly.
- Ask to create a routine to open the Routines editor. Saved routines retain their step review and verified run results.

## Voice capture and response efficiency

- A recording starts with a fresh recognizer, preventing queued wake-word results from entering the next request.
- Mute suspends voice processing immediately. After five seconds, unused native microphone capture and the offline model are released. Brief toggles retain their warm capture graph.
- Unmuting restores capture and the model in parallel. A microphone that disconnects during startup is rejected and cleaned up before it can become active.
- Hidden visual work, repeated waveform writes, PCM copying and repeated local intent parsing are reduced without changing the familiar appearance.

## Workspace and everyday controls

Named workspaces coordinate existing project and app-session records. Guided audio setup checks the chosen input and local recognition explicitly. Personal backup controls cover supported collections and preserve review before replacement. News keeps source-based reading and optional follow-up questions.

Intro replay now keeps its own presentation mode, cancels when another app screen opens, and rejects callbacks from earlier replays. A stale timer can no longer send Settings back to Home through that path.

## Updating from Olanga

Open **Workspace → Apps / Updates**, choose **Check for updates**, then **Download** and **Install & restart**. Downloaded bytes are checked against the published checksum. The updater also preserves a complete status record while Windows replaces it, improving recovery reporting. Updates remain manual; this release does not enable unattended installation or automatic rollback.

The update into 1.6.1 uses the updater already installed in your current Olanga. Keep Olanga open until the download is verified, then use the separate install action.

## Validation

Release checks use isolated profiles, synthetic audio and disposable native fixtures. They do not establish physical-microphone quality, live Spotify compatibility or identical performance on every computer. See [validation](../VALIDATION.md) for the measured results and limitations, and [privacy](../../PRIVACY.md) for local storage and connected features.

The installer is unsigned because no publisher certificate has been configured. The release includes SHA256SUMS and build metadata alongside the installer.
