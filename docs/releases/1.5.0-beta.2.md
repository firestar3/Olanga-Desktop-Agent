# Olanga 1.5.0-beta.2

This correction focuses on the main controls and the request “Play Spotify and raise the volume to 75%.”

- Removed Quick ask and its shortcut. Workspace is the main top-bar button, using the existing colors, font and styling.
- “Play Spotify” can open Spotify when no media session exists, then resume the selected music. An accessible Play fallback requires one visible, enabled control with a freshly checked identity. Success requires Spotify to report a playing track.
- An unavailable Spotify player no longer discards a remaining, explicitly requested volume adjustment. The reply reports both outcomes; unrelated or dependent steps still stop on failure.
- Recognized local requests receive short acknowledgments describing their intent. Early voice acknowledgments vary while transcription is pending. Slow speech rates get a bounded acknowledgment timeout appropriate to the phrase.
- Added regression coverage for Spotify startup, unavailable playback, following volume commands, contextual acknowledgments and incomplete compound-action proposals.

The installer is unsigned and updates remain manual. Live Spotify playback after these corrections has not yet been verified: desktop interaction was stopped with Escape. Fixture results and packaging checks are recorded in [validation](../VALIDATION.md).
