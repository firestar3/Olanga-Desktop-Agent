# Olanga 1.5.0-beta.1

This preview expands Olanga's desktop tools while keeping its existing theme, local commands and manual update flow.

- Track action progress and speech separately, cancel remaining work, and correct a volume target without replaying completed steps.
- Save selected app window layouts and preview their restoration. Rename or move selected files with collision checks and checked undo.
- Search a project folder locally, review source excerpts and optionally ask Gemini for a cited answer.
- Create daily or weekly schedules and import one-off calendar events through Workspace.
- Pair optional browser and VS Code companions for selected content, saved tabs/documents, reviewed edits and existing editor tasks.
- Configure local conversation and WAV speech, explicitly start Gemini Live, or review individual HTTPS MCP tool calls.
- Start a temporary paired HTTPS phone remote for supported app, volume and timer commands.
- Recover a completed update download through an explicit update check. Prepare release signing and optional publisher verification for a future certificate.

The preview installer is unsigned. Optional integrations require setup; phone control needs a trusted local TLS identity. Calendar import does not synchronize accounts or expand recurring events. Schedules require Olanga to remain open or in the tray. Updates remain manual.
