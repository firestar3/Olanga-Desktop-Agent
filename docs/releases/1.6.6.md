# Olanga 1.6.6

Local Windows update with an optional timer card beside the corner orb.

- Enable **Settings → User preferences → Timer card → Pin timers beside Olanga**.
- Click or drag the handle to switch between up to five expanded timers, the next timer and a tucked handle.
- Switch between timers and live scores in their shared card position.
- The card disappears when the last timer is dismissed. Timers, alarms and reminders retain their existing deadlines.
- The orb's five-second and one-hour hide controls also hide the selected card. Entering Olanga hides the floating controls, and leaving restores them.

This local installer is unsigned. Website publication and the public GitHub release remain pending.
