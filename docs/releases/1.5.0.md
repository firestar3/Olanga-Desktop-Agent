# Olanga 1.5.0

Olanga 1.5.0 expands Workspace with saved app layouts, reviewed file operations, project search, schedules and optional connections. It keeps the existing theme and local command controls, with clearer progress and completion reporting throughout a request.

## Everyday commands

- **Workspace is the main top-bar button.** Quick ask and its shortcut have been removed. Workspace uses the shared colors, typography and controls.
- **Spotify can start without an existing player session.** “Play Spotify” opens the app when needed and attempts to resume the selected music. Success requires Spotify to report a playing track. If playback remains unavailable, Olanga explains it.
- **Compound requests retain an independent volume step.** For “Play Spotify and raise the volume to 75%,” a playback failure no longer discards the explicitly requested volume adjustment. The reply reports both outcomes; unrelated or dependent steps still stop on failure.
- **Acknowledgments reflect recognized requests.** Local commands receive a short description of the intended action. Early voice acknowledgments vary while transcription is pending, with enough time for slower speaking rates.
- **Progress separates actions from speech.** A speech failure does not erase a completed action. Cancellation stops remaining work, and explicit volume corrections update the target without reopening an app or repeating completed steps.
- **Voice input handles capture and playback more carefully.** Audio processing accounts for sample counts, capture gaps and device changes. Optional local speech suspends wake recognition while the answer plays.

## Work tools

Open **Workspace → Apps & updates → Work tools**:

- **Working sessions:** save selected supported app windows and their layout, preview a restore, and check each restored window.
- **Files:** preview renames or moves for selected local files on the same volume. Operations avoid overwriting files; Undo checks that the files have not changed.
- **Projects:** search a selected folder locally with source paths and line references. Review retrieved excerpts before optionally sending them with a question to Gemini for a cited answer.
- **Selected content:** ask about text you paste or explicitly share from a companion, with review before cloud submission.
- **Schedules:** create once, daily or weekly reminders and briefings. Olanga must remain open or in the tray; missed occurrences are grouped when it resumes.
- **Calendar:** import one-off events from an `.ics` snapshot, add preparation reminders, or explicitly request a Gemini checklist.
- **Browser & editor:** pair the bundled development companions for selected text, saved tabs/documents, reviewed edits and existing VS Code tasks.
- **Conversation:** configure a compatible local model or WAV speech server, or explicitly start a Gemini Live conversation. These answer paths do not run desktop tools.
- **MCP tools:** inspect tools from a trusted HTTPS endpoint and approve the exact arguments for each call. Credentials stay in memory.
- **Phone remote:** start a temporary HTTPS session and pair a phone for a single supported app, volume or timer command. Setup requires a local TLS certificate trusted by the phone.

Optional integrations remain off until you start them. Opening Work tools does not capture microphone audio or establish an external connection.

## Installation and updates

Download **Olanga-Setup-1.5.0.exe** from this release. Existing settings and saved data are retained when updating an installation. Users on 1.4.1 or later can also use **Workspace → Apps & updates → Check for updates**, followed by **Download update** and **Install & restart**.

Update checks, downloads and installation remain manual. A completed cached download can be recovered after restarting Olanga through an explicit check with fresh release metadata and a new checksum verification. Interrupted partial downloads restart when requested.

This installer is **unsigned**. The release includes its SHA-256 checksum and signing metadata. Signing support is ready for a future publisher certificate; a checksum establishes matching file bytes, not publisher identity. Automatic updates and automatic rollback remain disabled.

## Validation and current limits

The [validation record](../VALIDATION.md) reports the checks performed for this release and distinguishes automated fixtures from live Windows and provider checks.

The corrected **“Play Spotify and raise the volume to 75%”** path has automated routing and native-function fixture coverage. Live playback of that corrected request remains unverified; the earlier live observation exercised **Open Spotify**, and did not pass its sustained-volume check. No end-to-end live Spotify success is claimed for this release.

Optional browser/VS Code companions, physical-phone setup, physical microphone behavior, Gemini Live, and external MCP or local model/speech servers still need validation with the devices, accounts and hosts where they will be used. Gemini Live and on-device general dictation remain optional preview features. Calendar import does not synchronize accounts or expand recurring event rules. MCP does not support OAuth or local command servers.
