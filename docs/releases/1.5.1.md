# Olanga 1.5.1

Olanga's purple orb now has a transparent background across Windows. The app, taskbar, system tray, desktop and Start-menu shortcuts, installer, uninstaller and Windows Apps list use matching artwork, with dedicated icon sizes for different display scales.

## Update inside Olanga

Open **Workspace → Apps & updates → Check for updates**, then choose **Download update** and **Install & restart**. Olanga verifies the download and uses the existing installation location. Settings and saved data stay in place.

This flow is supported in Olanga 1.4.1 and later, including 1.5.0 preview builds. Update checks, downloads and installation remain user-initiated.

For a new installation, download **Olanga-Setup-1.5.1.exe** from this release.

## Build verification

Release checks now inspect transparency and every Windows icon size, and compare the icon resources embedded in the packaged app and installer against the checked-in artwork. The same assets are used for the uninstaller. The README's download links point to this patch release.

Local validation passed: 720 unit tests; update controls, renderer recovery and Workspace smoke checks; packaged startup and persistence; all nine embedded icon sizes in the application, installer and extracted uninstaller; the installed Apps-list icon; and loading the window/tray ICO directly from the packaged archive. The installer has been built and inspected; this validation did not replace the user's installed copy.
